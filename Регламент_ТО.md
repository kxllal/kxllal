# Регламент технического обслуживания
## программы «Система кэширования результатов операций с матрицами»

### 1. Общие положения

**Назначение документа.** Регламент определяет порядок технического обслуживания программы и обеспечивает стабильную работу системы кэширования результатов операций с матрицами.

**Область применения.** Документ распространяется на файлы `main.py`, `cache_manager.py`, `backup_manager.py`, `io_handler.py`, `tests.py`, файл кэша `cache.txt` и папку резервных копий `backup`.

**Ответственный:** Орлова Анна Игоревна, группа ИСП-31, 3 курс.

---

### 2. Плановое ТО

| Операция | Периодичность | Действия |
|-----------|--------------|-----------|
| Запуск тестов | Ежемесячно | Выполнить команду `python tests.py` |
| Проверка операций с матрицами | Ежемесячно | Выполнить контрольное вычисление для тестовых матриц |
| Проверка работы кэша | Ежемесячно | Повторить вычисление и убедиться, что результат получен из кэша |
| Создание резервной копии | Еженедельно | Создать резервную копию файла кэша |
| Проверка версии Python | Ежегодно | Выполнить `python --version` |

---

### 3. Внеплановое ТО

| Операция | Действия |
|-----------|-----------|
| Восстановление кэша | Восстановить файл `cache.txt` из последней резервной копии |
| Ошибка чтения матриц | Проверить файлы `matrix_A.txt` и `matrix_B.txt` |
| Повреждение кэша | Выполнить восстановление и повторное тестирование |
| Программа не запускается | Проверить наличие и работоспособность Python |

---

### 4. Контроль качества

Программа считается работоспособной, если:

- автоматические тесты завершаются успешно;
- результаты операций с матрицами вычисляются корректно;
- кэширование и извлечение результатов работают без ошибок;
- файл `cache.txt` доступен для чтения и записи;
- резервные копии создаются и восстанавливаются корректно;
- аварийные завершения программы отсутствуют.
