## 1. Цель

Целью разработки является создание консольной программы на языке Python для вычисления произведения матриц размером N×N с
использованием механизма кэширования результатов вычислений.(12 вариант)

## 2. Область применения

Программа предназначена для использования в учебном процессе, при выполнении практических работ и демонстрации принципов кэширования вычислений, работы с файлами и организации резервного копирования данных.

## 3. Определения, термины, сокращения

**Матрица** — прямоугольная таблица чисел размером N×N.

**Произведение матриц** — результат операции умножения одной матрицы на другую по правилам линейной алгебры.

**Кэш** — хранилище результатов ранее выполненных вычислений.

**Хеш матриц** — уникальный идентификатор пары матриц, используемый для поиска результата в кэше.

**Резервная копия** — копия файла кэша, сохраняемая в папке `backup`.

## 5. Краткое описание

Программа выполняет умножение матриц размером N×N. Матрицы могут вводиться пользователем через консоль или считываться из файлов `matrix_A.txt` и `matrix_B.txt`.

Перед выполнением вычисления программа проверяет наличие результата в кэше. Если результат уже был получен ранее, он извлекается из кэша без повторного выполнения вычислений.

Для файла кэша предусмотрены резервное копирование и восстановление.

## 6. Обзор программного средства

Программа работает под управлением операционных систем Windows, Linux и macOS и не требует прав администратора.

### 6.2. Пользовательский интерфейс

Программа использует текстовый интерфейс в консоли. Все сообщения выводятся на русском языке.

### 6.3. Аппаратный интерфейс

Используются стандартные устройства ввода и вывода: клавиатура и монитор.

### 6.4. Программный интерфейс

Используется язык Python 3 и стандартная библиотека Python.

### 6.5. Коммуникационный интерфейс

Не используется. Работа осуществляется локально на компьютере пользователя.

### 6.6. Ограничения по памяти

Для работы программы достаточно до 100 МБ оперативной памяти.

### 6.7. Операции

Запуск программы:

```bash
python main.py
```

Запуск тестов:

```bash

```

### 6.8. Требования к адаптации рабочих мест

Не предъявляются. Программа работает в любом каталоге после копирования файлов проекта.

### 6.9. Функциональное описание

Программа должна:

- выполнять умножение матриц размером N×N;
- принимать данные через консоль и через файлы;
- сохранять результаты вычислений в кэш;
- получать результаты из кэша при повторном вычислении;
- отображать содержимое кэша;
- создавать резервные копии кэша;
- восстанавливать кэш из последней резервной копии;
- корректно обрабатывать ошибки ввода данных и отсутствия файлов.

### 6.10. Характеристики пользователя

Пользователь должен уметь запускать программы из командной строки и работать с текстовыми файлами.

- Язык программирования — Python 3.
- Сторонние библиотеки не используются.
- Проект выполняется одним разработчиком.
